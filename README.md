# Wine baseline checkpoint

Individual project: Wine Cultivar Classification Under Irrelevant Features.

## Run

Run `python run_baseline.py` from any working directory. Place the original
`wine.zip` beside the script or one directory above it. If neither exists, the
script downloads the original archive from UCI. Install `requirements.txt` in
your chosen Python environment if necessary. No row is removed.

## Evaluation fixed before results

- Original features plus 0, 10, 50, or 100 independent N(0,1) noise columns.
- Noise seed 5421; larger conditions contain the smaller conditions' columns.
- Same outer stratified 5-fold splits, repeated 20 times, for every condition.
  Outer seed 5420. Each wine has exactly one held-out prediction per repeat.
- Inside every outer training fold, shuffled stratified 5-fold grid search:
  kNN k=1,3,...,31; logistic C=0.001,0.01,0.1,1,10,100,1000.
  Inner seed 6420 + zero-based outer-fold index.
- StandardScaler is fitted inside the pipeline, separately in each inner fold;
  the selected pipeline is refitted only on outer training data.
- Logistic regression uses L2 regularization, lbfgs, max_iter=5000, tol=1e-6.
  With three classes this solver fits multinomial logistic regression.
- Uniform-weight Euclidean kNN; additional tuned unscaled kNN on original data.
- Outer held-out scores never choose the grid, seed, scaler or parameters.
  Grid ties use GridSearchCV's first maximum (ascending k or C).
- Overall accuracy is the mean of 20 complete out-of-fold accuracies, with each
  wine weighted equally. Repeat SD describes sensitivity to data partitioning.

## Error bars and limits

The 95% percentile bootstrap intervals use 10,000 class-stratified resamples
of wine IDs (seed 5422). Each wine's 20 out-of-fold correctness values are kept
together and averaged before resampling. The same bootstrap IDs are used for
every model and noise level. This avoids treating 3,560 repeated predictions as
independent wines. Models are NOT retrained during this bootstrap. Intervals
are conditional descriptive intervals for the saved out-of-fold predictions,
not full confidence intervals accounting for refitting on a new training sample.
Training overlap, fixed noise realization, small sample size and this classic
dataset limit inference. Do not infer significance merely from overlapping or
nonoverlapping plotted bars. Noise seed is fixed, not selected for a large gap.
